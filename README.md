FC 온라인 감독 모드에서 모은 **FC 채굴량**을 시즌별·기간별로 정리해 보여주는 Windows 데스크톱 프로그램입니다.

> 🔑 **API 키 등록 안내 (꼭 읽어주세요)**
> FCMS는 **Nexon Open API 키**로 매치 데이터를 받아옵니다.
> 키는 무료로 5분 안에 발급받을 수 있으며, 프로그램 안의 🔑 버튼을 누르면
> **도움말 창에서 단계별로 안내**됩니다. 자세한 이유는 아래 [왜 API 키를 직접 발급받아야 하나요?](#-자주-묻는-질문) 항목을 참고해주세요.

> ⚠️ **주의사항**
> 본 프로그램은 FC 온라인 공식 공개 API만을 사용해 **본인의 매치 기록을 받아와 통계로 정리**하는 도구입니다.
> 게임 내 어떤 동작에도 개입하지 않으며, 비정상적인 사용에 따른 책임은 사용자 본인에게 있습니다.

## ✨ 주요 기능

- 🔑 **본인 API 키로 직접 조회** — nexon에서 무료 발급받은 키로 본인 매치를 직접 가져옵니다. 프로그램 안의 🔑 버튼 → 도움말에서 단계별 발급 방법을 안내합니다
- 🪪 **닉네임만 입력하면 끝** — 키 등록 후엔 닉네임 한 줄로 자동 동기화
- 📅 **다양한 기간 선택** — 오늘 / 어제 / 최근 7·30·90일 / 시즌별 / 사용자가 직접 지정한 기간
- 📈 **5가지 분석 탭**
  - **개요** — 전체 요약 카드 + 채굴량 막대 차트
  - **시간대 패턴** — 24시간 중 언제 가장 활발했고, 어느 시간대 승률이 좋았는지
  - **요일 패턴** — 월요일부터 일요일까지 활동량과 승률 비교
  - **추이** — 시간이 지남에 따른 승률·FC 채굴량 변화 (꺾은선 차트)
  - **분포** — 새벽·오전·오후·저녁 / 평일·주말 / 승·패 분포를 도넛으로 시각화
- 👥 **여러 계정 등록·전환** — 닉네임이 다른 계정도 자유롭게 관리
- 💾 **데이터 영구 보관** — 한 번 받아온 매치는 PC에 저장되어, 시간이 갈수록 시즌 전체 통계가 완성됩니다
- 🔄 **자동 업데이트** — 새 버전이 나오면 프로그램이 알림. 버튼 한 번으로 설치
- 🖱️ **마우스 호버 툴팁** — 차트 위에 마우스를 올리면 해당 구간의 상세 수치 표시

## 📂 설치 및 사용 방법

1. 위쪽 **DOWNLOAD** 버튼으로 `FCMS.zip`을 받습니다
2. 압축을 푼 폴더(예: `D:\FCMS\`)를 원하는 위치로 옮깁니다
3. 폴더 안의 **`FCMS.exe`** 를 더블 클릭해 실행
4. 첫 실행 시 같은 폴더에 `data/` 폴더가 자동 생성되어 모든 데이터가 그 안에 저장됩니다
5. **별도로 설치할 프로그램은 없습니다** (Python·라이브러리·폰트 모두 exe 안에 포함)

> 처음 실행할 때 Windows Defender 또는 SmartScreen 경고가 뜰 수 있습니다.
> 서명되지 않은 개인 개발 프로그램이라 그렇습니다. **"추가 정보 → 실행"** 으로 진행해 주세요.

## 🚀 처음 사용해보기

### 1단계 — API 키 등록 (최초 1회만)

1. 프로그램 실행 후 우측 상단의 **황금색 🔑 버튼**을 누릅니다
2. 작은 창이 뜨면 **도움말** 버튼을 눌러 발급 안내를 확인합니다
3. 안내에 따라 nexon 사이트에서 무료로 키를 발급받아 복사합니다 (5분 이내)
4. 키를 입력 필드에 붙여넣고 **저장** 을 누릅니다
5. 인디케이터가 🟢 **초록색**으로 바뀌면 등록 완료입니다

> 키는 본인의 PC에만 저장되며, **외부에 공유하면 안 됩니다**.

### 2단계 — 계정 추가 및 첫 동기화

1. 상단의 **추가** 버튼 클릭
2. FC 온라인 닉네임 입력 → 확인
3. 자동으로 최근 매치 데이터를 받아옵니다 (보통 10 ~ 30초)
4. 받기가 끝나면 통계 카드와 차트가 표시됩니다

### 3단계 — 통계 살펴보기

1. **시즌** 또는 **기간** 드롭다운에서 보고 싶은 범위를 선택
2. 상단 탭(개요 / 시간대 / 요일 / 추이 / 분포)을 눌러 다양한 분석 화면 전환
3. 새로운 매치가 쌓이면 **지금 동기화** 버튼으로 다시 받아오세요

## 🔁 자동 업데이트

- 프로그램이 켜질 때 백그라운드에서 새 버전이 있는지 확인합니다
- 새 버전이 있으면 화면 상단에 알림 배너가 표시됩니다
- 배너의 **업데이트** 버튼을 누르면 자동으로 다운로드 후 재시작합니다 (관리자 권한 불필요)
- 수동으로 확인하려면 화면 우측 하단의 **업데이트 확인** 링크를 누르세요

## 📌 알아둘 점

- **30일이 지난 매치는 받아올 수 없습니다.** FC 온라인 시스템 상의 제약이며, 첫 동기화 시 받아오는 매치는 최근 30일치까지입니다
- 그래서 **30일 안에 최소 한 번씩은 동기화**해주세요. 그 사이 진행한 매치가 빠짐없이 저장되어 데이터 공백이 생기지 않습니다
- 한 번 받아온 매치는 PC의 `data/` 폴더에 **영구 보관**됩니다
- 매치를 자주 하시는 분(하루 100판 이상)은 **매일 동기화**를 권장합니다
- **챔피언스 / 슈퍼챔피언스 매치만** 통계에 포함됩니다 (다른 디비전은 FC 보상이 없어 채굴 통계 대상이 아닙니다)
- **FC 정책**: 챔피언스 승 +15, 슈퍼챔피언스 승 +20 (몰수승도 동일 적립)
- **무승부 매치는 통계에서 제외**되어 "전적 = 승 + 패"가 보장됩니다

> 프로그램 안의 **자세히** 버튼을 누르면 위 내용을 팝업으로 자세히 안내합니다.

## ❓ 자주 묻는 질문

**Q. 왜 API 키를 직접 발급받아야 하나요?**
초기에는 개발자가 운영하는 중계 서버를 통해 데이터를 받아왔습니다. 사용자가 늘면서 그 서버의 사용량 한도가 빠르게 차오르고, 매월 비용 부담도 커져 **한 사람이 안정적으로 운영하기 어려운 상황**이 됐습니다.
직접 nexon에서 키를 받아 사용하면:
- 본인의 사용량 한도만 쓰므로 **다른 사용자의 영향을 받지 않습니다**
- 응답이 더 빨라집니다 (중계 서버를 거치지 않으므로)
- 발급은 **무료**이며 5분이면 끝납니다
프로그램의 🔑 버튼 → 도움말을 누르면 캡처와 함께 단계별로 안내됩니다.

**Q. API 키가 노출되면 어떻게 되나요?**
나의 일일 사용량을 다른 사람이 소진할 수 있습니다. 만약 노출됐다면 nexon Open API 페이지의 본인 애플리케이션에서 **키 재발급** 또는 **삭제 후 재등록**이 가능합니다. 키를 새로 발급받은 뒤 FCMS의 🔑 버튼 → **변경** → 새 키로 교체해 주세요.

**Q. 동기화한 데이터를 다른 PC로 옮기고 싶어요.**
`FCMS.exe`가 있는 폴더의 `data/` 폴더를 통째로 새 PC의 같은 위치에 복사하시면 그대로 사용할 수 있습니다. API 키도 이 폴더에 함께 저장되어 있어 별도 재입력이 필요 없습니다. 다만 `data/` 폴더는 본인 외 누구와도 공유하지 마세요.

**Q. 계정을 삭제하면 데이터도 같이 지워지나요?**
삭제 시 "데이터 파일도 함께 삭제할까요?"라고 물어봅니다.
- **예** → 매치 데이터까지 모두 삭제 (되돌릴 수 없음)
- **아니오** → 계정 목록에서만 제거하고 데이터 파일은 보존 (나중에 같은 닉네임으로 다시 추가하면 자동 복원)

**Q. 시즌 시작부터의 모든 매치가 보이지 않아요.**
FC 온라인 시스템 상 30일 이전 매치는 받아올 수 없습니다. 처음 사용을 시작한 시점이 시즌 중반 이후라면, 그 이전 매치는 안타깝지만 받아올 방법이 없습니다. 이후로는 동기화만 꾸준히 해주시면 매치가 빠짐없이 누적됩니다.

**Q. 동기화가 너무 오래 걸려요 / 멈춘 것 같아요.**
처음 동기화는 최근 30일치 매치를 다 받아오기 때문에 매치 수에 따라 10초 ~ 30초 정도 걸립니다. 그 이후 동기화는 새로 추가된 매치만 받아오므로 보통 몇 초 만에 끝납니다. 진행 표시줄이 멈춘 것처럼 보여도 내부적으로는 계속 동작 중이니 잠시 기다려 주세요.

**Q. 닉네임이 바뀌었어요.**
프로그램 상단의 **닉네임 변경** 버튼을 사용하시면 됩니다. 같은 계정이라면 데이터는 그대로 유지되고 표시되는 닉네임만 갱신됩니다.

**Q. 기간을 직접 정해서 볼 수 있나요?**
네. 기간 드롭다운에서 **사용자 정의…** 를 선택하면 시작일과 종료일을 직접 입력할 수 있습니다. 선택한 기간은 다음 실행에도 그대로 유지됩니다.

**Q. 업데이트할 때 받아둔 매치 기록이나 API 키가 사라지지 않나요?**
사라지지 않습니다. 업데이트는 `FCMS.exe` 파일 자체만 새 버전으로 교체하며, `data/` 폴더(매치 기록 + API 키 + 설정)는 그대로 유지됩니다.

## 💾 데이터 저장 위치

`FCMS.exe`가 있는 폴더의 `data/` 폴더 안:

```
FCMS.exe
└── data/
    ├── fc_stats_meta.json         (등록된 계정 목록)
    ├── fc_stats_<계정ID>.db       (계정별 매치 데이터)
    └── window_state.json          (창 위치/크기 + UI 설정 + API 키)
```

이 폴더 안의 파일은 직접 수정·삭제하지 마세요. 프로그램이 자동으로 관리합니다.
**`data/` 폴더는 본인 외 누구와도 공유하지 마세요** — API 키가 포함되어 있습니다.
