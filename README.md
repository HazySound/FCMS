# FCMS — FC 채굴 통계

FC 온라인 감독 모드에서 챔피언스 / 슈퍼챔피언스 매치를 진행하며 모은 **FC 채굴량**을
한눈에 정리해서 보여주는 Windows 데스크톱 프로그램입니다.

넥슨 공식 사이트나 인게임에서는 보기 어려운 "내 FC 채굴 추이"를 시즌별, 날짜별로
확인할 수 있습니다.

---

## 주요 기능

- 닉네임만 입력하면 자동으로 최근 매치 기록을 받아와 통계로 정리합니다
- 시즌별 **FC 채굴량 / 매치 수 / 승률 / 챔스·슈챔 분리 전적**을 카드로 표시
- 일별 FC 채굴 막대 차트 + **일 평균 기준선**으로 잘 한 날 / 못 한 날 한눈에 비교
- 차트 막대에 마우스를 올리면 그날의 상세(승·패·판수·FC) 툴팁 표시
- **여러 계정** 등록 및 자유롭게 전환 가능
- 한 번 받아온 매치는 PC에 영구 보관되어, 시간이 갈수록 시즌 전체 통계가 완성됩니다

---

## 설치 및 실행

1. [Releases](../../releases) 페이지에서 최신 `FCMS.exe` 다운로드
2. 원하는 폴더(예: 바탕화면, `D:\FCMS\` 등)에 파일을 옮기고 **더블 클릭**
3. 첫 실행 시 같은 폴더에 `data/` 폴더가 자동으로 생성됩니다
4. **별도로 설치할 프로그램은 없습니다** (Python·라이브러리·폰트 모두 exe 안에 포함)

> 처음 실행할 때 Windows Defender 또는 SmartScreen 경고가 뜰 수 있습니다.
> 서명되지 않은 개인 개발 프로그램이라 그렇습니다. "추가 정보 → 실행"으로 진행해 주세요.

---

## 처음 사용해보기

1. 프로그램 실행 후 상단의 **추가** 버튼 클릭
2. FC 온라인 닉네임 입력 → 확인
3. 자동으로 최근 매치 데이터를 받아옵니다 (보통 10 ~ 30초)
4. 받기가 끝나면 통계 카드와 차트가 표시됩니다
5. 시즌 드롭다운에서 다른 시즌을 선택하면 그 시즌의 통계로 바뀝니다
6. 새로운 매치가 쌓이면 우측 하단의 **지금 동기화** 버튼으로 다시 받아오세요

---

## 알아둘 점

- **30일이 지난 매치는 받아올 수 없습니다.** FC 온라인 시스템 상의 제약이며,
  첫 동기화 시 표시되는 매치는 최근 30일치까지입니다.
- 그래서 **30일 안에 최소 한 번씩은 동기화**해주세요. 그 사이 진행한 매치가
  빠짐없이 저장되어 데이터에 공백이 생기지 않습니다.
- 한 번 받아온 매치는 PC의 `data/` 폴더에 **영구 보관**됩니다.
- 매치를 자주 하시는 분(하루 100판 이상)은 **매일 동기화**를 권장합니다.
- **챔피언스 / 슈퍼챔피언스 매치만** 통계에 포함됩니다
  (다른 디비전은 FC 보상이 없어 채굴 통계 대상이 아닙니다).
- **FC 정책**: 챔피언스 승 +15, 슈퍼챔피언스 승 +20 (몰수승도 동일 적립)
- **무승부 매치는 통계에서 제외**되어 "전적 = 승 + 패"가 보장됩니다.

> 프로그램 안의 **자세히** 버튼을 누르면 위 내용을 팝업으로 자세히 안내합니다.

## 자주 묻는 질문

**Q. 동기화한 데이터를 다른 PC로 옮기고 싶어요.**
`FCMS.exe`가 있는 폴더의 `data/` 폴더를 통째로 새 PC의 같은 위치에 복사하시면
그대로 사용할 수 있습니다. 별도 설정은 필요 없습니다.

**Q. 계정을 삭제하면 데이터도 같이 지워지나요?**
삭제 시 "데이터 파일도 함께 삭제할까요?"라고 물어봅니다.
- **예** → 매치 데이터까지 모두 삭제 (되돌릴 수 없음)
- **아니오** → 계정 목록에서만 제거하고 데이터 파일은 보존 (나중에 같은 닉네임으로 다시 추가하면 자동 복원)

**Q. 시즌 시작부터의 모든 매치가 보이지 않아요.**
FC 온라인 시스템 상 30일 이전 매치는 받아올 수 없습니다. 처음 사용을 시작한
시점이 시즌 중반 이후라면, 그 이전 매치는 안타깝지만 받아올 방법이 없습니다.
이후로는 동기화만 꾸준히 해주시면 매치가 빠짐없이 누적됩니다.

**Q. 동기화가 너무 오래 걸려요 / 멈춘 것 같아요.**
처음 동기화는 최근 30일치 매치를 다 받아오기 때문에 매치 수에 따라
10초 ~ 30초 정도 걸립니다. 그 이후 동기화는 새로 추가된 매치만 받아오므로
보통 몇 초 만에 끝납니다. 진행 표시줄이 멈춘 것처럼 보여도 내부적으로는
계속 동작 중이니 잠시 기다려 주세요.

**Q. 닉네임이 바뀌었어요.**
새 닉네임으로 **추가** 버튼을 눌러 등록해 주세요. 동일 계정이라면 데이터는
그대로 유지되고 표시되는 닉네임만 갱신됩니다.

## 데이터 저장 위치

`FCMS.exe`가 있는 폴더의 `data/` 폴더 안:

```
FCMS.exe
└── data/
    ├── fc_stats_meta.json         (등록된 계정 목록)
    ├── fc_stats_<계정ID>.db       (계정별 매치 데이터)
    └── window_state.json          (창 위치/크기 기억)
```

이 폴더 안의 파일은 직접 수정·삭제하지 마세요. 프로그램이 자동으로 관리합니다.
