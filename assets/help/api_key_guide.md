# Nexon Open API 키 발급 안내

FCMS는 본인의 매치 기록을 받아오기 위해 **Nexon Open API 키**가 필요합니다.
이 키는 누구나 무료로 5분 안에 발급받을 수 있으며, 발급받은 키는 **본인의 PC에만 저장**됩니다.

## ⚠️ 키 관리 주의사항

- **발급받은 키는 절대 외부에 공유하지 마세요.** (디스코드, 카페, 스트리밍 화면 등)
- 키가 유출되면 다른 사람이 본인의 quota를 소진할 수 있습니다.
- 의심되면 nexon Open API 페이지에서 키를 재발급할 수 있습니다.

---

## 0. 사전 준비

- nexon 계정이 필요합니다. 없으신 경우 nexon.com 에서 회원가입을 먼저 진행해 주세요.

---

## 1. 애플리케이션 등록 페이지 접속

아래 링크를 눌러 nexon Open API 등록 페이지로 이동한 뒤 nexon 계정으로 로그인합니다.

[LINK:https://openapi.nexon.com/ko/my-application/create-app/|애플리케이션 등록 페이지 열기]

![](step1.png)

---

## 2. 애플리케이션 정보 입력

아래 캡처의 **빨간 네모** 부분을 따라 입력합니다.

![](step2.png)

각 항목 옆의 **복사** 버튼을 누르면 클립보드에 복사되어 그대로 붙여넣을 수 있습니다.

- 앱 이름:  [COPY:FCMS]
- 앱 설명:  [COPY:FC온라인 감독모드 경기기록을 조회하여 승률 통계를 확인할 수 있는 서비스입니다.]
- 서비스 URL:  [COPY:https://github.com/HazySound/FCMS]

입력이 완료되면 페이지 하단의 등록 버튼을 눌러 주세요.

---

## 3. 등록한 애플리케이션 선택

등록이 완료되면 애플리케이션 목록으로 이동합니다.
방금 등록한 항목을 캡처의 **빨간 네모**처럼 클릭해 상세 화면으로 들어갑니다.

![](step3.png)

---

## 4. API 키 복사

상세 화면에서 캡처의 **빨간 네모** 부분이 **API 키 복사 버튼**입니다.
이 버튼을 누르면 발급된 키가 자동으로 클립보드에 복사됩니다.

![](step4.png)

> 키는 영문/숫자로 이루어진 긴 문자열입니다. 복사된 키를 별도로 확인할 필요는 없으며, 바로 아래 단계로 진행하시면 됩니다.

---

## 5. FCMS에 키 등록

1. 도움말 창을 닫습니다.
2. 팝오버의 입력 필드에 복사한 키를 붙여넣습니다 (`Ctrl+V`).
3. **저장** 버튼을 누릅니다.
4. 인디케이터가 🟢 **초록색**으로 바뀌면 등록 완료입니다.

이후 동기화는 본인의 키로 nexon에 직접 요청되며, 본인의 quota만 소진합니다.

---

## 자주 묻는 질문

**Q. 키가 노출되면 어떻게 해야 하나요?**
nexon Open API 페이지의 본인 애플리케이션에서 **키 재발급** 또는 **애플리케이션 삭제 후 재등록**이 가능합니다. 재발급 후 FCMS에 새 키를 다시 입력해 주세요.

**Q. 한 키로 여러 사람 통계를 볼 수 있나요?**
가능합니다. 본인이 발급한 키 하나로 본인 계정뿐 아니라 친구/가족 닉네임의 매치도 조회할 수 있습니다 (단, 본인의 일일 호출 한도를 공유합니다).

**Q. 다른 PC로 옮길 때 키를 다시 입력해야 하나요?**
PC를 옮길 때 `data/` 폴더를 함께 복사하시면 키도 같이 따라옵니다. 다만 `data/` 폴더는 본인 외에 누구와도 공유하지 마세요.
